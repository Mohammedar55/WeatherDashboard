# 🌤️ Weather Dashboard

A beautiful, modern weather dashboard application that fetches real-time weather data from OpenWeather API.

## ✨ Features

- 🌍 **Search Weather by City** - Search for any city worldwide
- 📍 **Current Location** - Get weather for your current location
- 📊 **Current Weather Details** - Temperature, humidity, wind speed, pressure, visibility
- 📅 **5-Day Forecast** - Get weather predictions for the next 5 days
- ⏰ **Hourly Forecast** - Hourly weather updates for the next 48 hours
- 💾 **Saved Cities** - Save your favorite cities for quick access
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 📱 **Responsive Design** - Works on all devices
- 🌐 **Arabic Support** - Full Arabic language support

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Internet connection
- OpenWeather API key (free at https://openweathermap.org/api)

### Installation

1. Clone the repository
```bash
git clone https://github.com/Mohammedar55/WeatherDashboard.git
```

2. Open `index.html` in your browser

3. Add your API key to `script.js`:
```javascript
const API_KEY = 'YOUR_API_KEY_HERE';
```

- **Provider**: OpenWeather (https://openweathermap.org/)
- **Free Tier**: 1000 calls/day
- **Endpoints Used**:
  - Current Weather
  - 5-Day Forecast
  - Geolocation Weather
